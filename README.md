# Solar Maintenance — admin website and engineer app

Front ends of the Solar Maintenance system for Shree Abhi Electricals & Engineering Pvt. Ltd.
They need the API from the companion repository **[Solar_Api](https://github.com/arun2796/Solar_Api)**.

**New to the project? Start here: [Local setup and test guide](https://github.com/arun2796/Solar_Api/blob/main/docs/LOCAL-SETUP.md)**. It covers both repositories, running everything locally, and a full test checklist.

| Folder | Contents |
|---|---|
| `admin-web/` | React + TypeScript + Vite admin website for the office. See [admin-web/README.md](admin-web/README.md) |
| `mobile/` | React Native + Expo Android app "Shree Abhi Solar" for field staff: maintenance visits/reports and site surveys in one app, shown by role and permissions. See [mobile/README.md](mobile/README.md) |
